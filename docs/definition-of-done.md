# Definition of Done (Feature)

- Contract-Änderungen sind in `src/shared/contracts` definiert.
- Client- und Server-Flow nutzen dieselben Eventnamen und Payloads.
- UI-Zustände für Loading/Success/Error sind berücksichtigt.
- Happy Path und relevante Error-Cases sind manuell oder per Tests geprüft.
- Keine unklaren Ownership-Fragen (authoritative source klar: Client oder Server).
